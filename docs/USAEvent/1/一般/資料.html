! 成功のコツ

  • ✅1つずつ順番に送る 【理由】複雑な指示を一度に行うと、AIの処理精度が低下する可能性があります。
  • ✅生成完了を待つ 【理由】生成途中の操作はコードの破損につながります。
  • ✅修正指示も具体的に 【理由】AIは完璧ではありません。的確な修正指示こそがAI活用の鍵です。

▶ 操作の手順

  1. 1 プロンプトをAIに送信 作成したいツールの仕様を伝えます。
  2. 2 「コードをコピーする」をクリック AIが生成したコードを取得します。
  3. 3 エディタに貼り付け 【理由】既存のコードを全置換することで、不整合を防ぎます。
  4. 4 保存して動作確認 実際にブラウザで動作を確認しましょう。

Step 1: チャットボットの基盤構築

🎯 ミッション Gemini APIのモデル「flash」を使用した、基本のチャットボットを作成します。

⚠️ "ここにAPIKeyを入れて" の部分を、ご自身のAPIキーに書き換えてください。 

GeminiのAPIを利用してチャットボットを作って下さい。
APIのセキュリティリスクは気にしないで下さい。

以下の環境で作成して下さい。
HTML, CSS, JavaScriptを1つのファイルにまとめて出力して
APIキーについては、コードの冒頭で const API_KEY = "ここにAPIKeyを入れて"; という変数で定義して、日本語で分かりやすいコメントを入れてください。
モデル：gemini-2.5-flash
APIエンドポイントバージョン：v1
APIKeyとモデルのバージョンは定数で指定できるようにして下さい。
※APIキー：AIを利用するためのパスワード

🎯 ミッション クリニックの基本情報（休日・営業時間など）を教え込み、受付としての役割を与えます。

Step 3: パラメータチューニング体験

💻 実践 生成されたコードを直接編集し、クリニック情報を変更してみましょう。
AIに再生成させるよりも、手動で修正した方が圧倒的に早いケースを体験しましょう。

// ↓ 以下の設定値を探して変更してください

const CLINIC_NAME = "宇佐内科医院";

const CLOSED_DAY = "火曜日";

▼

const CLINIC_NAME = "あなたの名前クリニック"; // 自分の名前に変更

const CLOSED_DAY = "日曜日"; // 定休日を変更

※変更後、「上書き保存」をしてブラウザを更新すると反映されます。

※注意：CLINIC_NAME や businessHours など、異なる変数名や書き方で生成される場合があります。「宇佐内科医院」という文字を手がかりに検索してください。

💡 AIマネジメントの極意

AIは「優秀な新人プログラマー」です。指示（仕様書）が曖昧だと迷いますが、用語（専門知識）を使って指示すれば完璧に動きます。

❌ 曖昧な発注

背景をいい感じにして

【理由】「いい感じ」の定義は人それぞれです。ビジネスシーンでの曖昧な発注と同様、手戻りの原因になります。

✅ 技術的な要件定義

背景に CSSアニメーション の @keyframes を使って、色がゆっくり変化する グラデーション (linear-gradient) を実装して

【理由】「CSSアニメーション」や「グラデーション」といった専門用語を使うことで、仕様ブレのない確実な実装が可能になります。
