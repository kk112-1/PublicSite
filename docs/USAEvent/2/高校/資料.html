! 成功のコツ

  • ✅1つずつ順番に送る 【理由】AIが一度に多くの命令を受けると、処理が追いつかずミスをしやすくなるからです。
  • ✅返事が終わるまで待つ 【理由】AIがコードを書き終える前に次の操作をすると、プログラムが途中で壊れてしまうからです。
  • ✅「今の直して！」も指示 【理由】AIは完璧ではありません。間違えた時にどう修正させるかが、AIを使いこなす一番のスキルです。

▶ 操作の手順

  1. 1 プロンプトをAIに送信 AIに「何を作ってほしいか」を伝えます。
  2. 2 終わったら「コードをコピーする」を押す AIが作った新しい「設計図」をまるごと取得します。
  3. 3 中身をすべて貼り付ける 【理由】古い内容をすべて消して入れ替えることで、新旧のコードが混ざる不具合を防ぎます。
  4. 4 保存して、動きを確認！ 指示がどう形になったか、実際に動かして確かめます。

Step 3: プログラミング体験

💻 チャレンジ AIが書いたコードを、あなたの手で直接書き換えてみましょう。
これを「パラメータ調整」と言います。プログラムの中身を少し変えるだけで、動作が変わることを体験しよう！

// ↓この部分を探して、数字を変えてみよう！

const WORK_TIME = 25 * 60;

const BREAK_TIME = 5 * 60;

▼

const WORK_TIME = 3; // 3秒でテスト！

const BREAK_TIME = 3; // 3秒休憩！

※書き換えたら「上書き保存」をして、画面を更新すると反映されます。

※注意：WORK_TIME や BREAK_TIME という名前は例です。AIによっては studyTime や pomodoroTimer など、違う名前で作ることもあります。「25」や「5」という数字を目印に探してみよう！

❌ おしい失敗例

背景をいい感じに光らせて！

【理由】「いい感じ」は人によって違います。AI任せにすると、思っていたのと違うデザインになってしまうことがあります。

✅ 賢い成功例（専門用語）

背景に CSSアニメーション の @keyframes を使って、色がゆっくり変化する グラデーション (linear-gradient) を実装して

【理由】「CSSアニメーション」や「グラデーション」という専門用語を使うことで、AIに正確な指示が出せます。
